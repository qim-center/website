## Overview

This tool analyses orientation in volumetric images using the structure tensor method. The structure tensor is a gradient-based method that can be used to estimate the local orientation and anisotropy in images.

## Usage

The tool can be used both as a standalone application and through our High Performance Computing platform. For large 3D image datasets that require cluster access, please contact us.
