## Overview

InSegt3D is an interactive segmentation tool that provides real-time full image segmentation from minimal user input. By providing a few scribbles, you get a complete segmentation of your 3D dataset.

## Features

- Real-time segmentation updates
- Works with 3D volumetric data
- Minimal user input required
