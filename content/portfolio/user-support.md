We aim to make using the Qim Platform and the qim3d library accessible and productive for everyone.

## Support for the Qim Platform

We have created a set of [tutorials](https://platform.qim.dk/tutorials) for new users to get familiar with using the platform. In addition, several [Jupyter Noteboooks](https://platform.qim.dk/notebooks) are available, showcasing the various features of the qim3d library. We also have a [FAQ](https://platform.qim.dk/faq) section.

In addition, we offer assistance with all aspects of using the Qim Platform

- access to the platform
- using the HPC cluster
  - problems directly with the HPC system should be resolved through the DTU Computing Center (DCC) [support](https://www.hpc.dtu.dk/?page_id=42)
- using platform tools

## Support for the qim3d library

To use the library, the installation guide can be found on our [GitHub](https://github.com/qim-center/qim3d) page. For more detailed instructions, look at our [documentation](https://docs.qim.dk/qim3d/), where you can also familiarise yourself with the details of the provided tools.

## Feedback and Contact

We value feedback from our users, so if you would like to see a new feature, found a bug or want to contribute code, please send an email, open an issue, or submit a pull request.

- Contact [page](https://platform.qim.dk/contact)
- Our Forum [page](https://forum.qim.dk/)
- Qim Platform [GitHub repo](https://github.com/qim-center/qim-platform)
- qim3d [GitHub repo](https://github.com/qim-center/qim3d)
