# The Qim Platform


The Quantitative Imaging Platform is an online environment designed for analysis of large-scale 3D imaging data. It provides tools for interactive visualization and quantitative analysis of volumetric datasets, making it especially useful for researchers working with µCT scans and other imaging techniques.
