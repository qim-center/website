## We do custom method development

Below you will find an overview of QIM developed software tools. The tools are free to use. Please respect the license restrictions mentioned with the code and remember to cite us appropriately. If you have any questions please contact us on info@qim.dk.

Most of the tools are also available on our High Performance Computing platform. If you wish to use the tools and have large 3D image data that require access to a cluster for analysis please get in touch with us.

- Structure tensor
- Relational Shape Measure
- Local thickness
- Layered Surface Detection
- Iterative Non Local Means Denoising
- Interactive Segmentation - InSegt
- Contour-based image meshing
