## Support for the qim3d library

To use the library, the installation guide can be found on our [GitHub](https://github.com/qim-center/qim3d) page. For more detailed instructions, look at our [documentation](https://docs.qim.dk/qim3d/), where you can also familiarise yourself with the details of the provided tools.

## Feedback and Contact

We value feedback from our users, so if you would like to see a new feature, found a bug or want to contribute code, please send an email, open an issue, or submit a pull request.
